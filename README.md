# PawShop — E-Commerce Pet Store

A single-page e-commerce web application built with React, Vite, Tailwind CSS, and Material-UI.

## Features
- **Product Catalog**: 12 pet products with names, prices, categories, and descriptions.
- **Product Details**: Dedicated details view with live stock indicator and quantity selector.
- **Search & Filter**: Real-time name search and pet-type category filters (All / Dog / Cat).
- **Shopping Cart**: In-memory cart with quantity controls, item removal, and Material-UI Table component.
- **Checkout & Validation**: Full checkout form with custom JavaScript regex validation for email and Philippine mobile numbers (`09XXXXXXXXX`).
- **Responsive & Clean UI**: Minimalist white/neutral design with custom pagination.

## Tech Stack
- React 18
- Vite
- React Router v6
- Tailwind CSS
- Material-UI (@mui/material, @mui/icons-material)
- PropTypes
